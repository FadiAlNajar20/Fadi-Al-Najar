# Fadi Al-Najar — Portfolio

A bilingual personal portfolio showcasing web development work and services, including landing pages, business websites, Shopify stores, and custom web applications.

## Live Portfolio

[portfolio-umber-nine-67.vercel.app](https://portfolio-umber-nine-67.vercel.app)

## Overview

- Arabic by default, with a full English version
- Right-to-left (RTL) and left-to-right (LTR) layouts
- Responsive across devices
- Accessible, SEO-friendly and performance optimized

## Built With

- React
- Vite
- Tailwind CSS
- React Icons

## Local Development

```bash
npm install
npm run dev       # start the development server
npm run build     # production build in dist/
npm run preview   # preview the production build
```

## Project Structure

```text
src/components   Page sections and UI components
src/i18n         Arabic and English text
src/constants    Contact details and project data
src/assets       Images and project screenshots
public           Icons, social preview images, robots.txt and sitemap
```
